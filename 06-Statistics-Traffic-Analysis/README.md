# Statistics & Traffic Analysis

## Overview

Wireshark provides statistical tools that help analysts understand overall network activity without inspecting every packet individually.

These tools summarize protocols, devices, conversations, traffic patterns, and potential network issues, making investigations faster and more efficient.

---



# Protocol Hierarchy

**Navigation**

```text
Statistics
    ↓
Protocol Hierarchy
```

**Purpose**

Displays all protocols present in the capture along with the percentage of traffic generated by each protocol.

**Useful For**

- Identifying dominant protocols
- Understanding captured traffic
- Deciding where to begin an investigation

---

# Endpoints

**Navigation**

```text
Statistics
    ↓
Endpoints
```

**Purpose**

Lists every unique device (IP address) involved in the capture.

**Displays**

- IP Address
- Packets
- Bytes
- Tx Packets
- Rx Packets

**Useful For**

- Finding the most active hosts
- Identifying communicating devices

---

# Conversations

**Navigation**

```text
Statistics
    ↓
Conversations
```

**Purpose**

Displays communication sessions between two endpoints.

**Displays**

- Source & Destination
- Packets
- Bytes
- Duration

**Useful For**

- Identifying important communication sessions
- Investigating device-to-device traffic

---

# IO Graphs

**Navigation**

```text
Statistics
    ↓
IO Graphs
```

**Purpose**

Visualizes network traffic over time.

**Useful For**

- Detecting traffic spikes
- Identifying unusual activity
- Investigating events at specific timestamps

---

# Expert Information

**Navigation**

```text
Analyze
    ↓
Expert Information
```

**Purpose**

Automatically highlights important network events detected by Wireshark.

**Displays**

- Chat
- Note
- Warning
- Error
- Retransmissions
- Duplicate ACKs

**Useful For**

- Quickly locating network issues
- Identifying packets that require further investigation
