# Wireshark 

A hands-on Wireshark learning repository documenting my journey from networking fundamentals to packet analysis and SOC investigations.

## Objectives

- Learn Wireshark from beginner to intermediate level.
- Understand how network communication works.
- Analyze packets using Wireshark.
- Practice protocol analysis and troubleshooting.
